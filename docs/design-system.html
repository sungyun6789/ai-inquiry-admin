원칙

모노톤

흰 배경과 무채색으로 화면을 구성합니다. 기존 관리자 화면의 톤을 그대로 유지했습니다.

강조는 한 곳에

검정 primary 버튼은 화면의 주요 동작 하나에만 씁니다. 목록 화면에서는 ‘문의 중요도 분류’, 로그인 화면에서는 ‘로그인’입니다.

색은 중요도에만

유채색은 문의 중요도 배지에만 씁니다. 다른 곳에 색이 없어야 급한 문의가 먼저 눈에 들어옵니다.

모서리와 크기

모서리

높이

간격은 Tailwind 간격 단위(1 = 4px)로 지정합니다. 버튼의 좌우 여백은 sm 12px, md 16px이고 입력창은 12px입니다. 표 칸은 좌우 16px, 위아래 12px이고 배지는 좌우 10px, 위아래 2px입니다.

Button

import { Button } from '@/components/ui/button';

<Button onClick={createInquiry}>문의 생성</Button>

사용 기준

  • primary는 화면에 하나만 둡니다. 나머지 동작은 secondary로 둡니다.
  • 표의 행 안에 들어가는 동작은 size="sm"을 씁니다.
  • 키보드로 포커스하면 foreground 색의 2px 외곽선이 2px 간격을 두고 표시됩니다.
  • disabled 상태의 스타일은 아직 없습니다.

사용 기준

  • 높이가 버튼 md와 같은 40px입니다. 로그인 화면은 입력창 두 개와 primary 버튼을 너비 400px 안에 세로로 쌓습니다.
  • 포커스 표시는 테두리 색 변화뿐이며 외곽선은 없습니다.
  • 테두리와 흰 배경의 대비는 1.26:1로, 입력창 경계에 대한 WCAG 1.4.11 기준(3:1)보다 낮습니다.

Badge

client/components/ui/badge.tsx

문의 중요도를 보여 주는 배지입니다. tone으로 색을 고르며 기본값은 neutral입니다.

tone

tone표시배경 / 글자중요도글자 대비
danger높음red-100 / red-700HIGH5.26:1
warning보통amber-100 / amber-700MEDIUM4.54:1
success낮음green-100 / green-700LOW4.50:1
neutral미분류neutral-100 / neutral-600null7.15:1

코드

import { Badge } from '@/components/ui/badge';

const PRIORITY_MAP = { HIGH: '높음', MEDIUM: '보통', LOW: '낮음' };
const PRIORITY_TONE = { HIGH: 'danger', MEDIUM: 'warning', LOW: 'success' } as const;

<Badge tone={v.priority ? PRIORITY_TONE[v.priority] : 'neutral'}>
  {v.priority ? PRIORITY_MAP[v.priority] : '미분류'}
</Badge>

사용 기준

  • 색만으로 구분하지 않고 항상 글자를 함께 씁니다.
  • warning(4.54:1)과 success(4.50:1)의 글자 대비는 AA 기준(4.5:1)에 걸쳐 있습니다. 색이나 글자 크기를 바꾸면 대비를 다시 확인합니다.

모든 부품은 className과 해당 HTML 요소의 속성을 받습니다.

코드

import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@/components/ui/table';

<Table className="table-fixed">
  <TableHeader>
    <TableRow>
      <TableHead className="w-[100px]">번호</TableHead>
      <TableHead>내용</TableHead>
      <TableHead className="w-[100px] text-center">-</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {inquiryList?.map((v) => (
      <TableRow key={v.id}>
        <TableCell className="truncate">{v.id}</TableCell>
        <TableCell className="truncate">{v.content}</TableCell>
        <TableCell className="text-right">
          <Button size="sm" onClick={() => deleteInquiry(v.id)}>삭제</Button>
        </TableCell>
      </TableRow>
    ))}
  </TableBody>
</Table>

등록일, 수정일, 중요도 칸은 생략했습니다.

사용 기준

  • 내용이 긴 표는 table-fixed로 칸 너비를 고정하고, 칸마다 truncate를 붙여 한 줄로 줄입니다.
  • 정렬 기본값은 <table>의 text-left입니다. 칸마다 text-center나 text-right로 바꿉니다.
  • 표가 화면보다 넓어지면 바깥 테두리 안에서 가로로 스크롤됩니다.

사용 시 주의

className은 덮어쓰지 않고 덧붙습니다

컴포넌트는 tailwind-merge 없이 className을 기본 클래스 뒤에 붙입니다. 같은 속성의 클래스가 겹치면 쓴 순서와 상관없이 Tailwind가 CSS를 생성한 순서로 적용됩니다. 그래서 칸마다 바꿔야 하는 정렬은 TableHead가 아니라 <table>에 text-left로 두었습니다. TableHead에 두면 text-center를 넘겨도 적용되지 않습니다.

색은 의미 토큰으로 지정합니다

화면 코드에서는 bg-neutral-900 같은 팔레트 클래스 대신 bg-primary 같은 의미 토큰을 씁니다. 토큰 값을 바꾸면 모든 화면에 함께 반영됩니다. 상태 색은 Badge의 tone으로만 씁니다.

테두리 색은 따로 지정하지 않습니다

border나 divide-y만 쓰면 색은 border 토큰이 됩니다. Tailwind 4의 테두리 기본색은 currentColor인데, globals.css의 @layer base에서 모든 요소의 기본 테두리 색을 border 토큰으로 바꿨기 때문입니다.
